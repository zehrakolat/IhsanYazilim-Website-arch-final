# İhsan Web Sitesi — Frontend

Statik tanıtım sitesi. Backend olmadan tam çalışır (bkz. `../backend/API-SPEC.md`).

- `Anasayfa.dc.html` — ana sayfa (tüm arayüz)
- `turkiye-kapsama.html` — Türkiye kapsama haritası
- `data.js` — canlı veri katmanı (API varsa çeker, yoksa statik veriye düşer)
- `config.js` — `IHSAN_API_BASE` burada tanımlanır (canlıya alma anahtarı)
- `support.js` — çalışma zamanı desteği
- `uploads/`, `logos/` — görseller
